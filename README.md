# Java Student Management

## 프로젝트 소개

Java 기초 문법과 객체지향 개념을 복습하기 위해 만든
콘솔 기반 학생 관리 프로그램입니다.

## 주요 기능

- 학생 추가
- 전체 학생 조회
- 학번으로 학생 검색
- 학생 정보 수정
- 학생 삭제
- 중복 학번 방지
- 잘못된 입력 예외 처리

## 프로젝트 구조

### Main
사용자 입력과 프로그램 실행 흐름을 담당합니다.

### Student
학생 한 명의 정보를 관리합니다.

### StudentManager
학생 목록과 학생 관리 기능을 담당합니다.

- Class / Object

## 구현하며 어려웠던 점

자바의 기초 지식을 많이 까먹었고, 거의 1년반 정도만에 다시 시작하는 느낌으로 하다보니
처음 개발환경구축부터 기본적인 코드설계등등이 어려웠던것 같고, 코드를 설계하는데 있어서
예를 들면 왜 여기엔 이런 코드가 들어가고, 왜 이런 오류가나고 적재적소에 코드들을 설계하는것이
어려움이 있었던것같습니다.


## 배운 점

직접 학생 관리 프로그램을 설계하는데 있어서, 어떤 파일이 어떤 역할을 수행하는지
또한 중복된 코드를 간소화하며, 불필요한 자원을 지우고, 가독성 및 원활한 프로그램
실행을 위해 코드를 리팩터링 하는 부분을 조금 배운것 같고, 제가 잘 알지 못했던
개념들인 향상된 for문이나 try catch와 throw, Scanner의 제약 조건등을
확실하게 배웠던 프로젝트입니다.
